# Terminal Adventure Game

Papegaai Pokkie is ontvoerd door Snerk, the Extremely Magnificent. Kun jij het meisje helpen Pokkie terug te krijgen?

!!! info

    De Terminal Adventure Game is beschikbaar voor Windows, Linux en macOS.


!!! opdracht-basis-thuis "Missie: papegaai Pokkie terughalen"

    ## Windows

    1. [Download het zip bestand](https://github.com/natuurkundepracticumamsterdam/Terminal-Adventure-Game/archive/refs/heads/main.zip) en pak deze uit.
    2. Open de uitgepakte map en open daarna ook de mappen `Terminal Adventure Game - Windows - EN` en `forest`.
    3. Open het bestand `start.bat` en start jouw missie!

    ## macOS

    1. [Download het zip bestand](https://github.com/natuurkundepracticumamsterdam/Terminal-Adventure-Game/archive/refs/heads/main.zip) en pak deze uit.
    2. Open de uitgepakte map en open daarna ook de map `Terminal Adventure Game - macOS - EN`.
    3. Klik met twee vingers (of control-click) op de map `forest` en kies **Services > New Terminal at folder** of **Voorzieningen > Nieuw Terminal-venster bij map**.
    3. Type `./start` en start jouw missie!

    ## Linux

    1. [Download het zip bestand](https://github.com/natuurkundepracticumamsterdam/Terminal-Adventure-Game/archive/refs/heads/main.zip) en pak deze uit.
    2. Open een terminal en cd naar de uitgepakte map, en dan naar `Terminal Adventure Game - Linux - EN` en `forest`.
    3. Type `./start` en start jouw missie!
